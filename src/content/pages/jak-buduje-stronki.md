## Moja filozofia

Stronę internetową buduję jak produkt, nie szablon. Każda decyzja techniczna ma uzasadnienie w wynikach — prędkości, dostępności i pozycji w Google.

## Stack technologiczny

- **Astro** — ultra-szybki generator statycznych stron
- **Tailwind CSS** — utility-first CSS bez zbędnego kodu
- **GitHub Pages** — hosting zero kosztów, maksymalna niezawodność
- **GitHub API CMS** — własny panel edycji treści bez serwera

## Proces pracy

1. Analiza potrzeb i konkurencji
2. Projekt struktury URL i architektury informacji
3. Budowa komponentów i szablonów
4. Optymalizacja Core Web Vitals
5. Wdrożenie i monitoring
